# 班时钟

一个放在桌面右下角的上下班倒计时工具。它会显示距离上班、午休、下班和加班结束还有多久，也会驻留在系统托盘中。

## 下载和安装

打开 [GitHub Releases](https://github.com/sheyingxin1204/work-countdown/releases)，下载最新版本的安装包：

- `BanClock-Setup-x.y.z.exe`：推荐使用，包含开始菜单、桌面快捷方式和开机自启选项。
- `BanClock.exe`：便携版，下载后可以直接运行。

安装时可以按需要勾选桌面快捷方式和开机自启。安装完成后，班时钟会自动出现在屏幕右下角。

## 基本使用

- 左键拖动窗口可以调整位置。
- 右键打开菜单，可以进入设置、查看工作统计、检查更新或退出程序。
- 关闭窗口时，程序会隐藏到系统托盘；从托盘菜单可以重新显示。
- `Ctrl+Shift+B` 显示或隐藏悬浮窗，`Ctrl+Shift+S` 打开设置中心。Windows 安装版支持全局快捷键。

## 设置中心

在设置中心可以修改：

- 上午上班、午休开始、下午上班和下午下班时间。
- 周末、节假日和调休工作日。
- 自定义工作时段和加班结束时间。
- 主题、透明度、窗口置顶、右下角边距和紧凑模式。
- 提前提醒、免打扰时段和提示音。
- 进度条按自然时间或实际工作时长计算。

### 工作日历

点击“同步官方日历”可以获取所选年份的节假日和调休安排。同步结果会保存在本地，网络不可用时会继续使用缓存；手动填写的日期会保留。同步后点击“保存设置”即可生效。

### 工作统计

右键菜单中的“工作统计”会显示今日、近 7 天和本月的工作时长，也可以导出 CSV。统计只记录班时钟运行期间识别到的工作时段，电脑休眠时间不会被计入。

### 多显示器

程序会根据鼠标所在的显示器定位窗口。右键菜单中的“移动到当前显示器”可以随时把窗口移到另一块屏幕。

## 更新和卸载

右键菜单选择“检查更新”即可检查新版本。已安装版本会先退出旧程序，再校验、替换并重启；更新失败时会恢复旧版本。

卸载可以在 Windows 的“应用和功能”中完成。用户配置和统计数据位于 `%APPDATA%/BanClock`，卸载前后都可以自行保留或删除。
